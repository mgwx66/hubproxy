🐳 Docker 镜像加速

支持多种镜像仓库，在镜像名称前添加本站域名即可加速下载。

🚀 支持的加速场景

面向开发者、运维人员和需要下载开源项目资源的用户，快速生成可复制、可打开的加速链接。

GitHub Release 下载加速

适用于 GitHub 项目发布页中的安装包、压缩包、二进制文件和其他 Release 附件下载。

GitHub Raw 文件加速

支持 raw.githubusercontent.com 与 gist.githubusercontent.com 文件链接，适合脚本、配置文件和源码文件下载。

Docker 镜像拉取加速

支持 Docker Hub、ghcr.io、quay.io、registry.k8s.io 等镜像仓库，降低镜像拉取失败和超时概率。

Hugging Face 文件加速

支持 huggingface.co 与 cdn-lfs.hf.co 仓库资源，适合模型文件、数据集文件和 LFS 文件下载。

📘 使用方法

  1. 复制需要下载的 GitHub、Hugging Face 或 Docker 相关链接。
  2. 粘贴到上方输入框，点击“获取加速链接”。
  3. 复制生成后的链接，或点击“打开链接”直接访问下载。
  4. Docker 镜像可在镜像名称前添加 wget.la/，例如 docker pull wget.la/nginx。

❓ 常见问题

WGET.LA 支持哪些 GitHub 链接加速？

支持 github.com、raw.githubusercontent.com、gist.githubusercontent.com 等常见 GitHub 文件、Release 附件和 Raw 文件链接。

如何使用 Docker 镜像加速？

在镜像名称前添加 wget.la 域名即可，例如 docker pull wget.la/nginx，也支持 ghcr.io、quay.io、registry.k8s.io 等镜像仓库。

是否支持 Hugging Face 下载加速？

支持 huggingface.co 和 cdn-lfs.hf.co 相关仓库文件链接，可通过输入框自动生成加速链接。

Docker 镜像加速

支持多种镜像仓库，在镜像名称前添加本站域名即可加速下载。

Docker 官方镜像： docker pull /nginx Docker 镜像： docker pull /user/image ghcr.io 镜像： docker pull /ghcr.io/user/image Quay.io 镜像： docker pull /quay.io/org/image Kubernetes 镜像： docker pull /registry.k8s.io/pause:3.8
